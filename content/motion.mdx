# Motion Elements Demo

This is regular MDX content.

<MotionDiv
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.8 }}
  className="p-5 bg-blue-600 rounded-lg text-white mb-5"
>
  This content fades in and moves up!
</MotionDiv>
