# Smooth Interactive Venn Diagram

This Venn Diagram smoothly animates when hovered, inspired by [Josh W. Comeau's blog](https://www.joshwcomeau.com/blog/why-my-blog-is-closed-source/).

<div className="relative flex justify-center items-center h-[500px] w-full">

{/* Left Circle */}

{" "}

<MotionDiv
  initial={{ scale: 1 }}
  whileHover={{ scale: 1.15 }}
  transition={{ type: "spring", stiffness: 60, damping: 10 }}
  className="absolute w-64 h-64 bg-blue-400 bg-opacity-50 rounded-full left-1/4"
></MotionDiv>

{/* Right Circle */}

{" "}

<MotionDiv
  initial={{ scale: 1 }}
  whileHover={{ scale: 1.15 }}
  transition={{ type: "spring", stiffness: 60, damping: 10 }}
  className="absolute w-64 h-64 bg-red-400 bg-opacity-50 rounded-full right-1/4"
></MotionDiv>

</div>

---

## **What Makes This Special?**

- **No Borders** – Clean & minimalistic.
- **Smooth Hover Animation** – Uses **spring physics** instead of abrupt scaling.
- **Soft Opacity Overlap** – Looks visually pleasant.
- **Bigger Circles** – More focus on smooth interactions.

This is a **great example of using animation for subtle interactivity**! 🚀
