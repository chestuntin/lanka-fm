# Motion Experiments

This document demonstrates various **motion effects**, including easing functions, staggered animations, different paths, and unique interactions.

---

## 1️⃣ Easing Functions

Different easing curves can dramatically change how smooth or snappy an animation feels.

### **Ease-In**

<MotionDiv
  initial={{ opacity: 0, y: -50 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 1, ease: "easeIn" }}
  className="p-4 bg-blue-600 rounded-lg text-white mb-5"
>
  This fades in with **ease-in** (slower start).
</MotionDiv>

### **Ease-Out**

<MotionDiv
  initial={{ opacity: 0, y: -50 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 1, ease: "easeOut" }}
  className="p-4 bg-green-600 rounded-lg text-white mb-5"
>
  This fades in with **ease-out** (slower end).
</MotionDiv>

### **Ease-In-Out**

<MotionDiv
  initial={{ opacity: 0, y: -50 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 1, ease: "easeInOut" }}
  className="p-4 bg-yellow-500 rounded-lg text-white mb-5"
>
  This fades in with **ease-in-out** (smooth start and end).
</MotionDiv>

## 2️⃣ Staggered Animations

Elements appearing one after another in a sequence.

<MotionDiv
  initial="hidden"
  animate="visible"
  variants={{
    visible: { transition: { staggerChildren: 0.3 } },
  }}
>
  <MotionDiv
    initial={{ opacity: 0, x: -50 }}
    animate={{ opacity: 1, x: 0 }}
    transition={{ duration: 0.5 }}
    className="p-3 bg-purple-600 rounded text-white my-2"
  >
    First item appears
  </MotionDiv>
  <MotionDiv
    initial={{ opacity: 0, x: -50 }}
    animate={{ opacity: 1, x: 0 }}
    transition={{ duration: 0.5, delay: 0.3 }}
    className="p-3 bg-indigo-600 rounded text-white my-2"
  >
    Second item appears
  </MotionDiv>
  <MotionDiv
    initial={{ opacity: 0, x: -50 }}
    animate={{ opacity: 1, x: 0 }}
    transition={{ duration: 0.5, delay: 0.6 }}
    className="p-3 bg-red-600 rounded text-white my-2"
  >
    Third item appears
  </MotionDiv>
</MotionDiv>

## 4️⃣ Circular and Curved Paths

### **Arc Motion**

<MotionDiv
  initial={{ opacity: 0, pathLength: 0 }}
  animate={{ opacity: 1, pathLength: 1 }}
  transition={{ duration: 1.5, ease: "easeOut" }}
  className="p-4 bg-pink-500 rounded-lg text-white mb-5"
  style={{ transformOrigin: "center" }}
>
  Moves in an **arc** instead of a straight line.
</MotionDiv>

### **Circular Rotation**

<MotionDiv
  animate={{ rotate: [0, 360] }}
  transition={{ duration: 3, repeat: Infinity, ease: "linear" }}
  className="w-20 h-20 bg-orange-600 mx-auto rounded-full my-8"
></MotionDiv>

This **spins continuously** in a perfect loop.

## 🔥 **Summary**

- **Easing Functions**: Control how animations start and stop.
- **Staggered Effects**: Delay elements for a sequential appearance.
- **Non-Linear Motion**: Use Bezier curves for natural movement.
- **Curved Paths**: Move elements in arcs or circles.
- **Spring Physics**: Add bounce and elasticity.
- **Interactive Animations**: Hover, tap, and color changes.
- **Looping & Pulsing**: Make animations continuous and smooth.

With Framer Motion, you can create **engaging, interactive, and dynamic** animations effortlessly! 🚀
